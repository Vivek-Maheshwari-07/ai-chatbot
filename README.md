# 🤖 SmartBot – AI Chat Assistant

SmartBot is a web-based conversational AI chatbot built using Python and Flask.
It provides users with an interactive chat interface where they can ask questions, have general conversations, and receive intelligent responses from an AI model.

The goal of this project is to demonstrate how artificial intelligence can be integrated into a web application using a simple backend and an intuitive frontend chat interface.

This project highlights API integration, backend development, frontend interaction, and deployment of an AI-powered web application.

# ⚙️ How It Works

1. The user types a message in the chat interface.
2. The message is sent to the Flask backend through an API request.
3. The backend processes the message and forwards it to an AI model API.
4. The AI model generates a response.
5. The response is returned to the frontend and displayed in the chat window.

This creates a smooth conversational experience similar to modern AI assistants.

```id="ejh62k"

```

## 4. Run the Application

```id="zh41m1"

```

